# Methodology

Each abstract scenario carries normalized hypotheses for radiative response,
ozone risk, stratospheric heating, precipitation shift, persistence, and
evidence quality. Monte Carlo draws perturb climate sensitivity and coupling.
The result reports a 95th-percentile risk proxy, mean distributional inequality,
termination-risk proxy, and expected knowledge gain.

Governance is part of the model rather than a README footnote. Independent
review, a public registry, international consultation, and reversible research
each contribute to a gate score. Non-reversible work receives zero research
priority. This is a transparent normative choice that users can inspect.
